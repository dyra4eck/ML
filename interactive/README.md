# Интерактивный тренажёр по лабораторным

`index.html` — страница, на которой можно по шагам прогонять алгоритмы обеих лабораторных и смотреть, что меняется.

- Лаба 1: тот же алгоритм итерации по ценностям действий на FrozenLake (числа совпадают с `lab1/q_iteration.py`).
- Лаба 2: DQN на упрощённой среде (модуль движется только по вертикали, два действия). Это не LunarLander, но алгоритм тот же.

Сборка из частей: `cat head.html; core.js и ui.js в тегах <script>` (см. историю коммита). `core.js` — логика без интерфейса, её можно запускать в Node.
